About Us

About Us:

This is a website created by Paul Novencido and Justin Quan, we created this website as part of COMP 3612, a Web Development course. It is a website that allows users to shop for products and use filters to do so. We also implemented a shopping cart feature that lets users keep everything they are considering buying while they are shopping.

Technologies Used:

To develop this project, we utilized HTML, Javascript, CSS, and Tailwind CSS, to structure elements, and style. We also utilized DummyJSON API to fetch data, and localStorage for the cart feature to ensure that a user's cart doesn't get randomly reset.
